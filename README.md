# 🇫🇷 Тренажёр французских глаголов

Мобильное PWA-приложение для изучения спряжения неправильных французских глаголов.

## 🚀 Возможности

- ✅ 18 неправильных глаголов
- ✅ 4 временные формы (Présent, Passé Composé, Imparfait, Futur Simple)
- ✅ Три режима: Практика, Обучение, Прогресс
- ✅ Работает офлайн
- ✅ Сохранение прогресса
- ✅ Адаптивный мобильный дизайн

## 📱 Установка на телефон

### Вариант 1: Через GitHub Pages (рекомендуется)

1. Откройте репозиторий на GitHub
2. Перейдите в **Settings → Pages**
3. Включите GitHub Pages (ветка `main`, папка `/ (root)`)
4. После деплоя откройте ссылку вида `https://ваш-логин.github.io/название-репо` на телефоне
5. Установите как приложение:
   - **Android (Chrome):** Меню (⋮) → "Установить приложение" или "Добавить на главный экран"
   - **iPhone (Safari):** Кнопка "Поделиться" → "На экран «Домой»"

### Вариант 2: Создание APK файла

Если нужен именно APK файл для установки:

```bash
# Установите зависимости
npm install

# Инициализируйте Capacitor
npx cap init

# Добавьте Android платформу
npx cap add android

# Синхронизируйте веб-файлы
npx cap sync

# Откройте проект в Android Studio
npx cap open android
```

В Android Studio:
1. Откройте проект
2. Нажмите **Build → Build Bundle(s) / APK(s) → Build APK(s)**
3. APK файл появится в папке `android/app/build/outputs/apk/debug/`

Затем загрузите APK в раздел **Releases** на GitHub.

## 🛠️ Локальный запуск

```bash
# Используя Python
python -m http.server 8080

# Или используя Node.js
npx serve .

# Откройте в браузере
http://localhost:8080
```

## 🎯 Как использовать

1. **Практика:** Выбирайте глагол и время, вводите правильную форму
2. **Обучение:** Просматривайте таблицы спряжения всех глаголов
3. **Прогресс:** Отслеживайте статистику правильных ответов
